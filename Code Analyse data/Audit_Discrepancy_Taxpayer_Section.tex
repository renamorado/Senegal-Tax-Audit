\section{Audit Discrepancies and taxpayer dissatisfaction with the audit process.}
\label{sec:audit_discrepancy_taxpayer}
\providecommand{\sym}[1]{\ifmmode^{#1}\else\(^{#1}\)\fi}

This section studies whether larger discrepancies between notified and confirmed audit amounts are associated with taxpayer-reported efficiency and corruption perceptions.

\subsection{Current empirical steps (updated main specification)}
\begin{enumerate}
\item Start from \texttt{datasetforanalysis.dta}.
\item Keep selected program cases and remove safety/replacement cases:
\begin{verbatim}
keep if selection == 1
drop if safeties == 1
\end{verbatim}
\item Recreate cluster groups used in fixed effects:
\begin{verbatim}
capture drop clusterid
egen clusterid = group(inspectorclusteryear)
\end{verbatim}
\item Recreate Table C5 dispute variables (\texttt{d1}--\texttt{d21}) exactly as in the main analysis script.
\item Construct the discrepancy regressor used in the current regressions:
\[
W_{\text{main}}=\frac{\text{notificationvalue}-\text{confirmationvalue}}{\text{notificationvalue}}
\]
\item Build panel indicators:
\begin{verbatim}
selfreported_audit = 1 if q28a in [2018,2021] or q29a in [2018,2021]
\end{verbatim}
Panel A uses \texttt{q1 != . \& selfreported_audit == 1}; Panel B uses \texttt{q1 != .}.
\item Build index outcomes as in taxpayer-survey code:
\begin{verbatim}
index_efficiency  from q31 q33 q41
index_corruption  from q32_inverted q42 q34   (swindex)
\end{verbatim}
\item Estimate Table 6 / D7-style columns by audit type (full, desk, all) with regressors:
\begin{verbatim}
W_main algorithm overlap random safeties horsprogramme
\end{verbatim}
Index outcomes use \texttt{a(selectionyear center)}; question outcomes (\texttt{q34 q35 q32 q42}) use \texttt{a(inspectorclusteryear)}.
\end{enumerate}

\subsection{Regression equation and notation}

Let \(i\) index a firm-audit observation in the merged administrative audit and taxpayer-survey data.
For each outcome \(o\), panel \(p\in\{A,B\}\), and column \(c\in\{\text{Full},\text{Desk},\text{All}\}\), we estimate:
\[
Y_{iopc}
= \beta_{opc} W_i
+ \boldsymbol{\theta}_{opc}^{\prime}\mathbf{M}_i
+ \lambda_{opc}(i)
+ \varepsilon_{iopc},
\]
where
\[
\mathbf{M}_i=
\big(\texttt{algorithm}_i,\texttt{overlap}_i,\texttt{random}_i,\texttt{safeties}_i,\texttt{horsprogramme}_i\big)'.
\]

We use:
\begin{itemize}
\item \(W_i=(\text{notificationvalue}_i-\text{confirmationvalue}_i)/\text{notificationvalue}_i\), defined when both values are strictly positive (operationally, \texttt{d4==1 \& d5==1 \& y2==1}).
\item Panel \(A\): \texttt{q1!=. \& selfreported\_audit==1}; Panel \(B\): \texttt{q1!=.}.
\item Column Full: \texttt{x2==1}; Column Desk: \texttt{x2==0}; Column All: no \texttt{x2} restriction.
\item Outcomes \(o\): indexes \(\{\texttt{index\_efficiency},\texttt{index\_corruption}\}\) and questions \(\{\texttt{q34},\texttt{q35},\texttt{q32},\texttt{q42}\}\).
\item Fixed effects \(\lambda_{opc}(i)\): \texttt{a(selectionyear center)} for index outcomes, and \texttt{a(inspectorclusteryear)} for question outcomes.
\end{itemize}
