\section{Audit Discrepancies and taxpayer dissatisfaction with the audit process.}
\label{sec:audit_discrepancy_taxpayer}
\providecommand{\sym}[1]{\ifmmode^{#1}\else\(^{#1}\)\fi}

This section studies whether larger discrepancies between notified and confirmed audit amounts are associated with taxpayer-reported dissatisfaction and corruption-related perceptions.

\subsection{Empirical steps}
\begin{enumerate}
\item Start from \texttt{datasetforanalysis.dta}.
\item Keep selected program cases and remove safety/replacement cases:
\begin{verbatim}
keep if selection == 1
drop if safeties == 1
\end{verbatim}
\item Keep one observation per firm's most recent selection year:
\begin{verbatim}
keep if recent == selectionyear
drop recent
\end{verbatim}
\item Recreate Table C5 dispute variables (\texttt{d1}--\texttt{d21}) exactly as in the main analysis script.
\item Construct the main discrepancy measure:
\[
W_{\text{main}}=\frac{\text{notificationvalue}-\text{confirmationvalue}}{\text{notificationvalue}}
\]
for cases with \texttt{y2==1}, \texttt{notification==1}, \texttt{confirmation==1}, and \texttt{notificationvalue>0}.
\item Restrict analysis sample to taxpayer survey respondents (\texttt{q1 != .}) when linking \(W_{\text{main}}\) to taxpayer outcomes.
\item Produce descriptive statistics for \(W_{\text{main}}\), by audit type and by selection method.
\item Run baseline and robustness regressions of taxpayer outcomes on discrepancy measures:
\begin{itemize}
\item baseline pooled: \(X\) on \(W_{\text{main}}\) with \texttt{i.x2};
\item controlled pooled: add \texttt{algorithm overlap random horsprogramme}, absorb \texttt{selectionyear} and \texttt{center};
\item split samples: full audits (\texttt{x2==1}) and desk audits (\texttt{x2==0});
\item discrepancy robustness: \(W_{\text{winsor}}\), ratio \texttt{d12}, and log-ratio \texttt{d11}.
\end{itemize}
\end{enumerate}
